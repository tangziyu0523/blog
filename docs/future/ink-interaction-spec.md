# 水墨交互层（Ink Layer）— 未来增强规格

> 状态：**未来可选模块**，未排期。依赖 M2 前端骨架完成后才实现。
> 性质：纯前端视觉增强，**不影响任何现有模块**，作为独立 feature 分支开发。

## 定位

纯前端视觉增强层，仅用于**首页 Hero** 和**关于页**两处。

- ❌ 不上文章阅读页（保证阅读性能与可读性）
- ❌ 不参与任何业务逻辑、数据流、SEO 关键路径
- ✅ 可随时下线，移除后页面回退到静态背景，无副作用

## 技术栈

| 项 | 选型 |
|----|------|
| 渲染 | 原生 WebGL + GLSL（不引入 three.js 等重型库） |
| 流体模拟 | 双 FBO（ping-pong framebuffer）流体着色器 |
| 滚动驱动 | GSAP + ScrollTrigger |

## 核心效果

- **鼠标速度映射笔触粗细**——移动越快，笔触越细越急；越慢越粗越润
- **点击生成墨斑晕染**——点击位置注入墨点，向外扩散晕染
- **墨水渗透 + 逐帧风干衰减**——墨迹随时间扩散并逐帧衰减「风干」
- **圆点光标跟随**——自定义圆点光标平滑跟随鼠标
- **滚动进度驱动**——滚动进度同时驱动水墨浓度变化与文字淡入

## 工程约束（必须实现）

1. **动态导入 `ssr: false`**——Next.js `dynamic()` 导入，仅客户端挂载，不进 SSR。
2. **`prefers-reduced-motion` 禁用**——命中时关闭动效，降级为静态背景。
3. **移动端降级**——移动端降级为静态宣纸纹理，不跑 WebGL 循环。
4. **不可见时暂停**——页面 / 标签页不可见时（`visibilitychange` / `IntersectionObserver`）暂停渲染循环，省电省 GPU。
5. **`multiply` 混合模式**——墨色与米白底以 multiply 融合，墨色压在底色上而非叠加发白。
6. **设计规范统一**——与博物学设计规范一致：米白底、衬线字、暖红强调色。

## 降级矩阵

| 条件 | 表现 |
|------|------|
| 桌面 + 允许动效 + WebGL 可用 | 完整水墨交互层 |
| `prefers-reduced-motion` | 静态背景，无动效 |
| 移动端 | 静态宣纸纹理 |
| 页面不可见 | 渲染循环暂停 |

## 依赖与排期

- **前置依赖**：M2 前端骨架完成。
- **开发方式**：独立 feature 分支，与主线解耦。
- **优先级**：可选增强，P0/P1/P2 主线功能完成前不动手。
